# Safety Disclaimer

This repository contains experimental design files and documentation for an operating-control interface concept related to a gas-fired pool heater.

The project is not certified, not approved by Pentair, and not suitable for installation or connection to a live heater. It is not a replacement for the OEM control board, ignition control module, safety systems, service manual, or a qualified technician.

Pentair and MasterTemp are referenced only to identify the appliance family being studied. This project is independent and is not affiliated with, endorsed by, sponsored by, or approved by Pentair.

No file in this repository should be interpreted as:

- Appliance repair instructions.
- Installation instructions.
- Approval to modify a gas appliance.
- A certified safety design.
- Permission to bypass any factory safety device.
- Permission for unqualified live electrical, gas, ignition, combustion, or venting work.

Any future bench or live-heater work must follow the official manual for the exact installed model, local code, applicable standards, and qualified professional review.

The design must remain fail-open for heat request and must never directly drive the gas valve.
