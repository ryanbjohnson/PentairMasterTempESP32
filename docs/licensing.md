# Licensing Notes

The repository currently uses the MIT License at the root.

MIT is simple and permissive, and it covers the repository as published unless a file states otherwise. It also includes a broad warranty disclaimer, which is important for a project that is not certified and not ready for live-appliance use.

Before the first public hardware release, consider whether the KiCad hardware design files should move to a hardware-specific license such as:

- CERN Open Hardware Licence Version 2 - Strongly Reciprocal (`CERN-OHL-S-2.0`).
- CERN Open Hardware Licence Version 2 - Weakly Reciprocal (`CERN-OHL-W-2.0`).
- CERN Open Hardware Licence Version 2 - Permissive (`CERN-OHL-P-2.0`).

Do not publish release artifacts until the intended license is clear in the root README, release notes, and generated fabrication package.
