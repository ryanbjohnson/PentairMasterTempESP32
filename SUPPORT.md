# Support

This repository does not provide appliance repair support, installation instructions, or emergency troubleshooting.

For heater service, gas, combustion, venting, electrical, or code-compliance questions, contact a qualified pool-heater technician and follow the official Pentair documentation for the exact installed model.

Use GitHub issues for:

- Repository setup problems.
- KiCad scaffold/test failures.
- Documentation improvements.
- Review of design assumptions.
- Non-urgent project planning.

Do not use GitHub issues for:

- Emergency heater problems.
- Requests to bypass safety systems.
- Live gas-valve, combustion, or ignition troubleshooting.
- Instructions for unqualified installation.

Safety or security-sensitive reports should follow `SECURITY.md`.
