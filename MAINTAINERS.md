# Maintainers

This project is currently maintained by the repository owner.

Maintainers should be able to review:

- KiCad schematic and PCB changes.
- Embedded-control safety boundaries.
- Gas-appliance interface risks.
- Test and release-gate documentation.

## Review Ownership

- Documentation-only changes: normal maintainer review.
- Schematic or PCB changes: maintainer review plus checks.
- Heat-request, relay, safety-input, watchdog, brownout, thermistor/SFS, or live-test changes: explicit safety review before merge.
- Public release artifacts: maintainer approval after checklist review.

Add named maintainers here when the GitHub repository has stable owners.
